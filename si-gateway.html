How it fits together

Two components. One seamless system.

SI Gateway is not a single device — it is a two-part system. The Gateway bridges your inverter to your network. The Core is the brain that orchestrates everything.

🔌
SI Gateway
The bridge — one per inverter

RS485 to Wi-Fi bridge. Sits in the DB or next to the inverter. Reads Modbus data and relays it to the SI Core over your local network. Pairs in minutes.

🧠
SI Core
The brain — one per site

Raspberry Pi pre-flashed with the SI platform. Runs Home Assistant, aggregates all gateway data, hosts the local dashboard and handles automation logic. One Core manages multiple Gateways.

Capabilities

Not just a data logger.

☀️

Real-Time Inverter Telemetry

Solar PV output, battery SOC, grid import/export and load — live on your dashboard. Every value that matters, always current.

🔒

Local-First Architecture

Runs on a Raspberry Pi on your LAN. Dashboard available at homeassistant.local — no cloud account required, no internet dependency for local monitoring and control.

🌐

Remote Access Without Port-Forwarding

View your system from anywhere via an encrypted managed tunnel. First 12 months included. No router configuration. No third-party tunnel service.

🏠

Home Assistant Native

Every inverter entity exposed via MQTT auto-discovery. No YAML required. Solar, battery, grid and load appear in HA the moment a broker is configured.

🔗

Multi-Inverter Support

One SI Core, multiple SI Gateways — for larger sites, multi-phase systems or properties with more than one inverter. Each Gateway pairs independently.

📈

Historical Analytics

Log inverter performance over time. Review daily solar yield, battery cycles, grid dependency and load patterns. Identify inefficiencies and anomalies across weeks and months.

🛠️

Remote Support Layer

Installers can access the system remotely for configuration, diagnostics and troubleshooting — with customer permission. Reduces callout costs for both parties.

🧠

Ecosystem Orchestration

SI Gateway is the coordination layer for the whole SI platform. It aggregates telemetry from SI Pool, SI Water and future products — enabling cross-domain automations like battery-aware heating and solar-surplus pool heating.
